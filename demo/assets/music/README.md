# Music sources

These four albums and their original cover files come from John Oestmann's
CC0 submissions on OpenGameArt. Release dates, track titles, and durations
come from the linked artist release pages. The covers are bundled unchanged;
`catalog.json` records their source URLs and SHA-256 hashes.

| a_new_day_in_the_workshop | [CC0 source](https://opengameart.org/content/anewdayintheworkshop-electronic-idm-album) | [Artist release](https://johnoestmannmusic.bandcamp.com/album/a-new-day-in-the-workshop) |

[CC0 1.0 dedication](https://creativecommons.org/publicdomain/zero/1.0/).
Sources checked on 2026-09-27. No audio files are included.

The demo keeps synthetic album and artist identifiers. Library ownership,
download progress, and request history are simulated, as for the other seeds.
The first two releases are owned; the other two can be requested.
Older historical compilation fixtures retain their generated cover art and
existing IDs so the queue, import, and request examples keep working.
