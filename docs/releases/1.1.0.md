# Cantinarr 1.1.0

## New

- Play Sun is the default logo across the app, web interface, launch screens, and desktop icons. On iOS and Android, choose Play Sign, Play Dome, or Original in Settings > Account > App icon. The choice is saved by the device.
- French interface support follows the device language or a saved choice in Settings > Account > Language.
- Media-user onboarding has separate Import users and Invite user actions, explicit account linking for Plex, Jellyfin, Emby, and Audiobookshelf, and clearer sign-in, request, and media-access status.
- Supported AI providers can fall back once to a provider-managed recommended model when the selected model is unavailable. The saved model choice stays unchanged, and the app identifies the replacement.

## Improved

- AI provider catalogs use current model IDs and the appropriate API or OAuth endpoint. Grok OAuth keeps its own catalog, and supported reasoning choices are preserved.
- Web scrolling avoids unnecessary redraws. Media artwork connections retry transient failures, authentication avoids repeated device-activity writes, and the server serves precompressed web assets.
- Container images use Alpine 3.24, and Docker builds use a registry mirror for their base images.

## Compatibility

The server and native app versions are 1.1.0 for this coordinated release. Compatibility floors are unchanged: the app supports servers from 0.6.0, and the server does not impose a minimum app version.
